
# PERSONAL EXPENSE TRACKER

A full-stack MERN (MongoDB, Express.js, React, Node.js) application that allows users to track their income and expenses with ease. The app includes features like category-wise expense tracking, real-time insights, authentication, and a responsive dashboard.



## Features

- 🔐 User Authentication (Email/Password & Google Sign-In via Firebase)
- 💵 Log Income and Expenses
- 📊 Visual Summary Dashboard
- 🏷️ Categorize Expenses (Food, Travel, etc.)
- 📆 Filter by Date Range (Last week/month/custom)
- 🌐 Responsive and User-friendly UI
- ☁️ Persistent Data Storage using MongoDB


## Tech Stack

| Frontend       | Backend     | Database | Auth      |
|----------------|-------------|----------|-----------|
| React          | Node.js     | MongoDB  | Firebase  |
| CSS            | Express.js  | Mongoose |           |


Install my-project with npm

```bash
git clone https://github.com/sathhyasv/personal_expense_tracker.git
cd personal_expense_tracker
```
Setup Backend

```bash
cd backend
npm install
nodemon index.js
```
Make sure MongoDB is running and environment variables are set in .env.

Setup Frontend

```bash
cd frontend
npm install
npm start
```


    
## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`MONGO_URI`




## Usage/Examples

Sign up or log in using Email/Password or Google.

Add your incomes and expenses.

View categorized reports and summaries.

Filter your transactions by date.
